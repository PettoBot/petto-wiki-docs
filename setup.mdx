## Overview

Setup covers the handful of server-wide settings every other system builds on.

<Steps>
  <Step title="Prefix">
    Change the command prefix with `/prefix`, slash commands work either way.
  </Step>
  <Step title="Saved embeds">
    Build reusable embeds with a variable engine using `/embed create`.
  </Step>
  <Step title="Browse commands">
    Run `/help` any time to browse every command without leaving Discord.
  </Step>
</Steps>

## Commands

| Command | Syntax | Description |
| --- | --- | --- |
| prefix | `/prefix [new_prefix]` | View or change the command prefix. |
| embed | `/embed <create\|edit\|delete\|preview\|send>` | Build and save named embeds with a variable engine. |
| help | `/help [command]` | Browse every command and how to use it. |

## Bot appearance

Petto's nickname, avatar, banner, and "about me" text in your server can all be customized from the dashboard's Customize page, real changes that apply to how the bot looks in your server, not just cosmetic on the site.

## Config export and reset

The dashboard's General page shows a live snapshot of the server's entire configuration, and lets you download it as JSON or reset the basics (prefix, mute role, bot appearance) back to defaults.
