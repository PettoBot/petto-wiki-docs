## Overview

Moderation gives every sanction a permanent, searchable case instead of a message that gets deleted and forgotten. Arguments are positional and space-separated, wrap anything with spaces (like a reason) in "quotes".

## Direct moderation commands

The grouped commands below also have direct prefix commands. They use the same case history, hierarchy checks, confirmation cards, and Discord permission checks.

<CodeGroup>

```javascript Syntax
!hardban <user> [reason]
!tempban <user> <duration> [delete_message_days] [reason]
!softban <user> [delete_message_days] [reason]
!tempmute <user> <duration> [reason]
!timeout <user> <duration> [reason]
!unban <user> [reason]
!unmute <user> [reason]
```

```javascript Example
!hardban @Spammer "Raid cleanup"
!tempban @Someone 7d 1 "Repeated warnings"
!softban @Spammer 3 "Clean recent spam"
!timeout @Someone 2h "Cooldown"
!unban 492810293847162839 "Appeal accepted"
```

</CodeGroup>

`hardban` bans the member and removes up to seven days of recent messages. `softban` bans and immediately unbans the member, keeping no lasting ban while cleaning recent messages. `tempmute` and `timeout` apply Discord's native timeout for up to 28 days. `unmute` also removes Petto's configured mute role when one is in use.

## Administrator bulk actions

These commands always require **Administrator** and ask for confirmation before changing several members at once.

<CodeGroup>

```javascript Syntax
!massban <users> [reason]
!masskick <users> [reason]
!massmute <users> [reason]
!massunmute <users> [reason]
!masswarn <users> <reason>
!massunban [reason]
```

```javascript Example
!massban @UserOne @UserTwo "Raid accounts"
!massmute @UserOne @UserTwo "Chat lockdown"
!masswarn @UserOne @UserTwo "Rule 3"
!massunban "Review completed"
```

</CodeGroup>

Users can be supplied as mentions or IDs, separated by spaces or commas. Bulk actions create individual cases where applicable, and Discord permissions plus role hierarchy still apply to every target.

## Ban

<CodeGroup>

```javascript Syntax
!ban user <user> [delete_message_days] [reason]
!ban users <users> [reason]
!ban temp <user> <duration> [delete_message_days] [reason]
!ban remove <user> [reason]
!ban remove-all [reason]
```

```javascript Example
!ban user @Spammer 0 "Raid bot"
!ban temp @Someone 7d 0 "Repeated warnings"
```

```text Result
✅ Case #12 · Ban
User: @Spammer (492810293847162839)
Moderator: @you
Reason: Raid bot
```

</CodeGroup>

`users` bans several members at once with the same reason (space or comma separated mentions/IDs). `remove-all` unbans every currently banned user and requires **Administrator**, it asks for confirmation first.

<Info>
  Every case Petto creates has this exact shape, see [Moderation Cases](/concepts/cases) for what each field means and how editing/deleting works.
</Info>

## Mute

<CodeGroup>

```javascript Syntax
!mute user <user> [reason]
!mute users <users> [reason]
!mute temp <user> <duration> [reason]
!mute remove <user> [reason]
!mute remove-users <users> [reason]
```

```javascript Example
!mute temp @Someone 2h "Cooldown"
!mute remove @Someone
```

</CodeGroup>

`user`/`users` mute indefinitely until manually removed. `temp` uses Discord's native timeout (max 28 days).

## Warn

<CodeGroup>

```javascript Syntax
!warn user <user> <reason>
!warn users <users> <reason>
```

```javascript Example
!warn user @Someone "Breaking rule 3"
```

</CodeGroup>

<Tip>
  Reason is **required** for warnings, unlike bans, kicks, and mutes where it's optional.
</Tip>

### Warn escalation

Automatic consequences once a member reaches a warning threshold, no manual follow-up needed.

<CodeGroup>

```javascript Syntax
!warn escalation add <threshold> <action> [duration]
!warn escalation remove <threshold>
!warn escalation list
```

```javascript Example
!warn escalation add 3 tempmute 1h
!warn escalation add 5 kick
!warn escalation add 7 ban
```

</CodeGroup>

`action` is one of `mute` (indefinite), `tempmute`, `kick`, or `ban`. `duration` is required when `action` is `tempmute`.

## Case

Every sanction gets a numbered case automatically.

<CodeGroup>

```javascript Syntax
!case list <user>
!case last <user>
!case last-many <users>
!case view <case>
!case edit <case> [duration] [reason]
!case edit-many <cases> [duration] [reason]
!case delete <case>
!case delete-all <user>
```

```javascript Example
!case list @Someone
!case view 42
!case edit 42 "Updated reason"
```

</CodeGroup>

## Role

<CodeGroup>

```javascript Syntax
!role add <user> <roles> [reason]
!role remove <user> <roles> [reason]
```

```javascript Example
!role add @Someone "Verified, Member"
```

</CodeGroup>

`roles` accepts several mentions/IDs/names at once, space or comma separated.

## Moderation access by role

Server managers can allow selected roles to use individual moderation actions without giving those roles Administrator. This does not bypass Discord permissions, Petto's role hierarchy, or the Administrator-only bulk rule.

<CodeGroup>

```javascript Syntax
!moderation allow <action> <role>
!moderation deny <action> <role>
!moderation reset <action>
!moderation list
```

```javascript Example
!moderation allow ban @Moderators
!moderation allow warn @Helpers
!moderation deny ban @Helpers
!moderation list
```

</CodeGroup>

Individual actions can be `ban`, `kick`, `softban`, `unban`, `mute`, `unmute`, `warn`, `case`, `note`, `role`, `channel`, `voice`, or `nuke`. The `ban` action covers `!ban`, `!hardban`, and `!tempban`; the `mute` action covers `!mute`, `!tempmute`, and `!timeout`. The exact Discord permission for the action remains required.

## Channel

<CodeGroup>

```javascript Syntax
!lock [channel] [role]
!unlock [channel] [role]
!slowmode <seconds> [channel]
!clear <amount> [user]
!hide [channel]
!unhide [channel]
!lockall
!unlockall
!moveall <destination>
```

The direct forms above are shortcuts for the grouped command. The grouped forms remain available:

```javascript Syntax
!channel lock [channel] [role]
!channel unlock [channel] [role]
!channel slowmode <seconds> [channel]
!channel clear <amount> [user]
!channel lock-all
!channel unlock-all
!channel hide [channel]
!channel unhide [channel]
!channel move-all <destination>
```

```javascript Example
!lock
!slowmode 10
!clear 50 @Spammer
!lockall
!moveall #AFK
```

Legacy spellings such as `!channel lockdown`, `!channel lock_all`, `!channel unlock_all`, and `!channel moveall` remain accepted.

```javascript Example
!channel lock
!channel slowmode 10
!channel clear 50 @Spammer
```

</CodeGroup>

`channel` and `role` default to the current channel and `@everyone` when omitted. `clear` deletes 1-100 recent messages, optionally filtered to one user.

## Mute role vs timeout

`!mute` uses Discord's native timeout by default, no role setup needed. If you'd rather use a dedicated mute role instead, set it on the dashboard's General page.
