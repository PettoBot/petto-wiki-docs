## Overview

Moderation gives every sanction a permanent, searchable case instead of a message that gets deleted and forgotten. Arguments are positional and space-separated, wrap anything with spaces (like a reason) in "quotes".

## Ban

<CodeGroup>

```javascript Syntax
!ban user <user> [delete_message_days] [reason]
!ban users <users> [reason]
!ban temp <user> <duration> [delete_message_days] [reason]
!ban remove <user> [reason]
!ban remove-all [reason]
```

```javascript Example
!ban user @Spammer 0 "Raid bot"
!ban temp @Someone 7d 0 "Repeated warnings"
```

</CodeGroup>

`users` bans several members at once with the same reason (space or comma separated mentions/IDs). `remove-all` unbans every currently banned user and requires **Administrator**, it asks for confirmation first.

## Kick

<CodeGroup>

```javascript Syntax
!kick user <user> [reason]
!kick users <users> [reason]
```

```javascript Example
!kick user @Someone "Being disruptive"
```

</CodeGroup>

## Mute

<CodeGroup>

```javascript Syntax
!mute user <user> [reason]
!mute users <users> [reason]
!mute temp <user> <duration> [reason]
!mute remove <user> [reason]
!mute remove-users <users> [reason]
```

```javascript Example
!mute temp @Someone 2h "Cooldown"
!mute remove @Someone
```

</CodeGroup>

`user`/`users` mute indefinitely until manually removed. `temp` uses Discord's native timeout (max 28 days).

## Warn

<CodeGroup>

```javascript Syntax
!warn user <user> <reason>
!warn users <users> <reason>
```

```javascript Example
!warn user @Someone "Breaking rule 3"
```

</CodeGroup>

<Tip>
  Reason is **required** for warnings, unlike bans, kicks, and mutes where it's optional.
</Tip>

### Warn escalation

Automatic consequences once a member reaches a warning threshold, no manual follow-up needed.

<CodeGroup>

```javascript Syntax
!warn escalation add <threshold> <action> [duration]
!warn escalation remove <threshold>
!warn escalation list
```

```javascript Example
!warn escalation add 3 tempmute 1h
!warn escalation add 5 kick
!warn escalation add 7 ban
```

</CodeGroup>

`action` is one of `mute` (indefinite), `tempmute`, `kick`, or `ban`. `duration` is required when `action` is `tempmute`.

## Case

Every sanction gets a numbered case automatically.

<CodeGroup>

```javascript Syntax
!case list <user>
!case last <user>
!case last-many <users>
!case view <case>
!case edit <case> [duration] [reason]
!case edit-many <cases> [duration] [reason]
!case delete <case>
!case delete-all <user>
```

```javascript Example
!case list @Someone
!case view 42
!case edit 42 "" "Updated reason"
```

</CodeGroup>

## Note

Non-punitive staff notes, separate from case history.

<CodeGroup>

```javascript Syntax
!note add <user> <note>
!note view <id>
!note list <user>
```

```javascript Example
!note add @Someone "Asked about appealing a ban, seemed genuine"
```

</CodeGroup>

## Role

<CodeGroup>

```javascript Syntax
!role add <user> <roles> [reason]
!role remove <user> <roles> [reason]
```

```javascript Example
!role add @Someone "Verified, Member"
```

</CodeGroup>

`roles` accepts several mentions/IDs/names at once, space or comma separated.

## Channel

<CodeGroup>

```javascript Syntax
!channel lock [channel] [role]
!channel unlock [channel] [role]
!channel slowmode <seconds> [channel]
!channel clear <amount> [user]
```

```javascript Example
!channel lock
!channel slowmode 10
!channel clear 50 @Spammer
```

</CodeGroup>

`channel` and `role` default to the current channel and `@everyone` when omitted. `clear` deletes 1-100 recent messages, optionally filtered to one user.

## Voice

<CodeGroup>

```javascript Syntax
!voice mute <user> [reason]
!voice unmute <user> [reason]
!voice deafen <user> [reason]
!voice undeafen <user> [reason]
!voice disconnect <user> [reason]
!voice move <user> <channel> [reason]
```

```javascript Example
!voice mute @Someone
!voice move @Someone #AFK
```

</CodeGroup>

## Mute role vs timeout

`!mute` uses Discord's native timeout by default, no role setup needed. If you'd rather use a dedicated mute role instead, set it on the dashboard's General page.
