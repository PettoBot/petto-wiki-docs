## Overview

Moderation gives every sanction a permanent, searchable case instead of a message that gets deleted and forgotten.

<Steps>
  <Step title="Take an action">
    Run `/ban`, `/kick`, `/mute`, or `/warn` on a member, with an optional reason and duration.
  </Step>
  <Step title="It gets a case">
    Every action gets a numbered case automatically, viewable later with `/case view`.
  </Step>
  <Step title="Temp actions expire on their own">
    Temporary bans and mutes expire on their own, no follow-up command needed.
  </Step>
</Steps>

## Commands

| Command | Syntax | Description |
| --- | --- | --- |
| ban | `/ban <user> [duration] [reason]` | Ban one or many members, permanent or temporary. |
| kick | `/kick <user> [reason]` | Kick one or many members. |
| mute | `/mute <user> [duration] [reason]` | Timeout a member, permanent or temporary, with auto-expiry. |
| warn | `/warn <user> [reason]` | Log a warning, optionally escalating after N warns, see [Warn Escalation](/moderation/warn-escalation). |
| case | `/case <list\|view\|edit\|delete> [case_id]` | List, view, edit, or delete moderation cases. |
| note | `/note <user> <text>` | Add a non-punitive staff note to a user. |
| role | `/role <add\|remove> <user> <role>` | Add or remove a role from a member. |
| channel | `/channel <lock\|unlock\|slowmode\|clear> [duration]` | Lock, unlock, slowmode, or clear a channel. |
| voice | `/voice <mute\|deafen\|disconnect\|move> <user> [channel]` | Mute, deafen, disconnect, or move members in voice. |

## Mute role vs timeout

`/mute` uses Discord's native timeout by default, no role setup needed. If you'd rather use a dedicated mute role instead, set it on the dashboard's General page.
