## Overview

Anti-nuke is a separate protection layer from automod, watching for mass-destructive actions: channel or role deletion sprees, or a wave of mass bans. When a member crosses the configured action threshold within the time window, Petto automatically strips their permissions.

## Configuration

| Setting | Description |
| --- | --- |
| Enabled | Turns the whole system on or off. |
| Action threshold | How many destructive actions within the window trigger a response. |
| Window (seconds) | The rolling time window the threshold is measured over. |
| Whitelist | User or role IDs exempt from anti-nuke entirely. |

<Warning>
  Add every co-owner and trusted admin bot to the whitelist before turning this on, anti-nuke can't tell the difference between a compromised account and a busy admin doing legitimate cleanup.
</Warning>

Configured entirely on the [dashboard](https://petto.sbs/dash)'s Moderation page.
