## Overview

Petto's nickname, avatar, banner, and "about me" text can all be customized per-server from the [dashboard](https://petto.sbs/dash)'s Customize page. These are real per-guild changes applied directly through Discord, not cosmetic-only on the site.

## What you can change

| Setting | Description |
| --- | --- |
| Nickname | Server-specific display name. |
| Avatar | Server-specific avatar image. |
| Banner | Server-specific profile banner. |
| About me | Server-specific bio text, shown on Petto's profile card. |

<Info>
  All four are scoped to your server only, they don't change how Petto looks anywhere else.
</Info>

Leave any field empty to fall back to Petto's global default for that server.
