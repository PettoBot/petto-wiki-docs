## Overview

Every command works identically as `/command` or as `<prefix>command`, nothing about a command's behavior changes based on which one you use.

## Commands

| Command | Syntax | Description |
| --- | --- | --- |
| prefix | `/prefix [new_prefix]` | View or change the command prefix. |
| help | `/help [command]` | Browse every command and how to use it, without leaving Discord. |

Run `/prefix` with no argument to see the current one, or `/prefix !` (for example) to change it.
