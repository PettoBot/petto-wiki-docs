## Overview

Two separate, independently configurable messages:

- **Boost message**: fires every individual boost (a member can apply more than one).
- **Level-up message**: only fires when the server's boost level itself goes up.

## Commands

<CodeGroup>

```javascript Syntax
!boost setup <channel> [embed] [message]
!boost level-up [embed] [message]
!boost status
!boost test
!boost disable
```

```javascript Example
!boost setup #boosts --message "{user} just boosted! {server_boostcount} total boosts."
!boost level-up --message "We just hit boost level {server_boostlevel}!"
```

</CodeGroup>

Both support every [variable](/resources/scripting/variables), and can each be a saved [embed](/resources/scripting/embeds).
