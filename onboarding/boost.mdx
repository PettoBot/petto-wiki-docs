## Overview

Two separate, independently configurable messages:

- **Boost message**: fires every individual boost (a member can apply more than one).
- **Boost tier reached message**: only fires when the server's boost level itself goes up.

## Commands

| Command | Syntax | Description |
| --- | --- | --- |
| boost | `/boost <channel> [message]` | Announce new boosts and boost-level changes. |

Both messages support every [variable](/resources/scripting/variables) and can be a saved [embed](/resources/scripting/embeds).
