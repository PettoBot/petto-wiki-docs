## Overview

Mentions a new member in one or more channels, then deletes the ping automatically, a way to trigger channel "new member" notifications without leaving a permanent mention in chat history.

## Commands

| Command | Syntax | Description |
| --- | --- | --- |
| poj | `/poj <enable\|disable> [role]` | "Ping on join": mention a new member, then clean it up. |

Pick which channels it fires in from the dashboard's Onboarding page.
