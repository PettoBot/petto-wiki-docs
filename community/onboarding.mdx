## Overview

Onboarding covers everything that happens the moment someone joins, from a welcome message to a verification gate.

<Steps>
  <Step title="Verification">
    Set the join-gate with `/verify setup`, backed by a real Cloudflare Turnstile captcha.
  </Step>
  <Step title="Join/leave/boost messages">
    Configure channel messages with `/welcome`, `/leave`, and `/boost`.
  </Step>
  <Step title="Beyond a channel post">
    Add a DM-on-join or a ping-on-join with `/dmonjoin` and `/poj` if you want more than a channel post.
  </Step>
</Steps>

## Commands

| Command | Syntax | Description |
| --- | --- | --- |
| verify | `/verify setup [role]` | Cloudflare Turnstile join-gate setup. |
| welcome / leave | `/welcome <channel> [message]` | Channel announcements on join and leave. |
| boost | `/boost <channel> [message]` | Announce new boosts and boost-level changes. |
| dmonjoin | `/dmonjoin <enable\|disable> [message]` | Send a DM to new members, separate from the channel welcome. |
| poj | `/poj <enable\|disable> [role]` | "Ping on join": mention a new member, then clean it up. |
| bumpreminder | `/bumpreminder <channel>` | Reminds the server to bump on Disboard. |

## Bump reminders

Beyond just the channel, the reminder and thank-you message are both customizable, and you can turn on auto-lock (locks the channel between bumps) and auto-clean (deletes chatter in the bump channel) independently.

## Boost tiers

The boost message and the boost-tier-reached message are separate: one fires per individual boost, the other only when the server's boost level actually increases.
