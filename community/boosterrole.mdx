## Overview

Boosters can create a custom colored role for themselves, and share it with a limited number of other members.

## Commands

| Command | Syntax | Description |
| --- | --- | --- |
| boosterrole | `/boosterrole <color> [name]` | A custom colored role for server boosters. |

## Configuration

| Setting | Description |
| --- | --- |
| Anchor role | Where booster roles get positioned in the role list. |
| Roles per booster | Max custom roles one booster can hold. |
| Share limit | Max members a booster can share their role with. |
| Color cooldown | How often the color can be changed. |
| Icon cooldown | How often the icon can be changed. |
| Rename cooldown | How often the name can be changed. |
| Filtered words | Words blocked from booster role names. |

<Info>
  Admins can also directly create, edit, or remove any member's booster role from the dashboard, not just the booster themselves.
</Info>
