## Overview

Tracks who invited whom, with a leaderboard of who's bringing in the most members.

## Commands

<CodeGroup>

```javascript Syntax
!invites user [user]
!invites top
```

```javascript Example
!invites user @Someone
!invites top
```

</CodeGroup>

`user` defaults to yourself if omitted. Purely a tracking/lookup feature, nothing to configure.
