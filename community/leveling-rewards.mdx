## Overview

Give a role automatically when a member reaches a specific level, and control how (and whether) a level-up gets announced.

## Role rewards

Add as many level-to-role pairs as you want on the dashboard's Leveling page. Role mode controls whether a member keeps every reward role they've earned, or only their highest.

## Announcements

| Setting | Description |
| --- | --- |
| Channel | Where level-ups post, or reply in place if left empty. |
| Every N levels | Only announce every N levels instead of every single one. |
| Style | Plain text or an embed. |
| Message | Fully custom text, supports every [variable](/resources/scripting/variables). |

## Join bonus

Optionally grant starting XP and a starting level to new members the moment they join.
