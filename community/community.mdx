## Overview

Community commands are the small utilities members use on themselves, day to day.

<Steps>
  <Step title="Reminders">
    Set a personal reminder with `/remind`, it DMs you when it's due.
  </Step>
  <Step title="AFK">
    Mark yourself away with `/afk`, it clears automatically on your next message.
  </Step>
  <Step title="Invites">
    Check the invite leaderboard with `/invites` to see who's bringing in members.
  </Step>
</Steps>

## Commands

| Command | Syntax | Description |
| --- | --- | --- |
| remind | `/remind <duration> [message]` | Set a personal reminder. |
| invites | `/invites [user]` | See who invited whom, and a per-server leaderboard. |
| afk | `/afk [reason]` | Mark yourself away, auto-clears on your next message. |
| boosterrole | `/boosterrole <color> [name]` | A custom colored role for server boosters. |
| report | `/report <user\|message> [reason]` | Report a message or user to staff. |

## Booster roles

Boosters can create a custom colored role for themselves, share it with a limited number of other members, and change its color/icon/name subject to a cooldown, all configurable on the dashboard (base role position, roles-per-booster limit, share limit, cooldowns, and a filtered-words list for names).

## Reports

`/report` and the "Report Message" context-menu action both send to the same destination channel, set it on the dashboard's Community page.
