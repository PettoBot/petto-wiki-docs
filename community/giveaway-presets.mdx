## Overview

A preset gives certain roles extra entries automatically when a giveaway uses it, no manual weighting needed each time.

## Commands

| Command | Syntax | Description |
| --- | --- | --- |
| giveawaypreset | `/giveawaypreset <add\|remove> <role> <entries>` | Role-based bonus entries and claim time. |

## Stacking

Each role's bonus can optionally stack with other matching roles a member has, configurable independently for:

- **Entries stacking**: a member with two bonus roles gets both bonuses added together.
- **Claim time stacking**: their extended claim window stacks too.

Without stacking, only the single best-matching role's bonus applies.
