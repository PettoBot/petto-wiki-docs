## Overview

Set a personal reminder, Petto DMs you when it's due.

## Commands

| Command | Syntax | Description |
| --- | --- | --- |
| remind | `/remind <duration> [message]` | Set a personal reminder. |

Purely personal, nothing to configure server-side.
