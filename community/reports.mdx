## Overview

`/report` and the "Report Message" right-click context-menu action both send to the same destination channel.

## Commands

| Command | Syntax | Description |
| --- | --- | --- |
| report | `/report <user\|message> [reason]` | Report a message or user to staff. |

Set the destination channel, and turn reports on or off, from the dashboard's Community page.
