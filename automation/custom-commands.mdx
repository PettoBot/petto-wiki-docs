## Overview

Create a command that replies with saved text or a saved [embed](/resources/scripting/embeds), and supports every [variable](/resources/scripting/variables).

## Commands

| Command | Syntax | Description |
| --- | --- | --- |
| customcommand | `/customcommand <add\|edit\|remove> <name> <response>` | Create a command that replies with saved text or an embed. |

## Plain text or embed

On the dashboard, a custom command can either have response text, or point at a saved embed template by name, if a template is picked it takes priority over the response text.
