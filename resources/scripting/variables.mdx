---
title: "Variables"
description: "All available variables in Petto."
icon: "signature"
---

These variables are available in welcome, leave, boost, level-up messages, autoresponders, custom commands, giveaway messages, bump reminders, and saved embeds. You can also browse this same list as a copy-to-clipboard dropdown right in the [dashboard](https://petto.sbs/dash), next to any field that supports them.

<Tabs>
  <Tab title="User">
    | Variable | Output |
    | --- | --- |
    | `{user}` | Mentions the user |
    | `{user.mention}` | Mentions the user (same as `{user}`) |
    | `{user.name}` | Username |
    | `{user.id}` | User ID |
    | `{user.avatar}` | Global avatar image URL |
    | `{user.display_avatar}` | Server avatar, falls back to global |
    | `{user.display_name}` | Server nickname, or username if none |
    | `{user.joined_at}` | Date they joined this server |
    | `{user.joined_at_timestamp}` | Unix timestamp of that join date |
    | `{user.created_at}` | Date the account was created |
    | `{user.created_at_timestamp}` | Unix timestamp of account creation |
    | `{user.boost}` | "Yes" or "No", are they boosting |
    | `{user.boost_since}` | Date they started boosting, or "Not boosting" |
    | `{user.boost_since_timestamp}` | Unix timestamp of boost start |
    | `{user.color}` | Highest role color as hex |
    | `{user.top_role}` | Their highest role name |
    | `{user.role_list}` | All their roles, mentioned |
    | `{user.bot}` | "Yes" or "No", is it a bot account |
    | `{user.join_position}` | Which member number they were |
    | `{user.join_position_suffix}` | Join position with suffix (1st, 2nd...) |
  </Tab>

  </Tab>

  <Tab title="Custom commands">
    <Info>
      Only available in [custom commands](/automation/custom-commands), including the saved embeds they send.
    </Info>

    | Variable | Output |
    | --- | --- |
    | `{args}` | All text after the command name |
    | `{arguments}` | Same as `{args}` |
    | `{args_raw}` | Same as `{args}`, keeps the full argument text |
    | `{arg1}` to `{arg10}` | The first to the tenth argument |
    | `{args_from:N}` | All arguments starting at position N, for example `{args_from:2}` |
    | `{arg_count}` | How many arguments were given |
    | `{command_name}` | The command name that was used |
    | `{prefix}` | The prefix that was used |

    Text in quotes counts as one argument, so `!hello "big world" now` has two. Mentions typed by the user inside an argument never ping anyone.
  </Tab>
  <Tab title="Sanctions">
    <Info>
      Only available in [sanction messages](/moderation/moderation#sanction-messages).
    </Info>

    | Variable | Output |
    | --- | --- |
    | `{case.id}` | The case number (not in the message sent to the member before a ban, kick or similar) |
    | `{case.type}` | `ban`, `tempban`, `softban`, `unban`, `kick`, `mute`, `tempmute`, `unmute`, `warn`, `jail` or `unjail` |
    | `{case.action}` | The action in words, such as "banned from" or "warned in" |
    | `{case.emoji}` | The icon of the action |
    | `{case.reason}` | The reason |
    | `{case.duration}` | How long it lasts, or Permanent |
    | `{case.expires}` | When it ends, as a relative time, or Never |
    | `{case.expires_at}` | When it ends, as a date and time, or Never |
    | `{case.source}` | Who applied it: a moderator, automod, the honeypot, warn escalation or an automatic expiry |
    | `{case.moderator}` | Mentions the moderator |
    | `{case.moderator_name}` | Name of the moderator |
    | `{case.moderator_id}` | ID of the moderator |
    | `{case.moderator_avatar}` | Avatar of the moderator |
    | `{case.user}` | Mentions the sanctioned member |
    | `{case.user_name}` | Name of the sanctioned member |
    | `{case.user_id}` | ID of the sanctioned member |
    | `{case.user_avatar}` | Avatar of the sanctioned member |
  </Tab>

  <Tab title="Quests">
    <Info>
      Only available in the saved embeds sent by [Quest alerts](/automation/quests).
    </Info>

    | Variable | Output |
    | --- | --- |
    | `{quest.name}` | Name of the quest |
    | `{quest.game}` | The game or brand |
    | `{quest.publisher}` | Who published it |
    | `{quest.id}` | ID of the quest |
    | `{quest.url}` | Link to accept the quest in Discord |
    | `{quest.link}` | Link to the game or brand page, empty if none |
    | `{quest.image}` | Banner picture of the quest, empty if none |
    | `{quest.logo}` | Logo of the game, empty if none |
    | `{quest.color}` | Main color of the quest as hex |
    | `{quest.reward}` | The rewards, with their type |
    | `{quest.reward_type}` | Type of the first reward: Orbs, Collectible, Code... |
    | `{quest.reward_amount}` | Number of Orbs, empty if the reward is not Orbs |
    | `{quest.reward_image}` | Picture of the first reward, empty if none |
    | `{quest.task}` | The first task, such as Watch a video |
    | `{quest.task_minutes}` | Minutes the first task takes |
    | `{quest.tasks}` | All the tasks with their time |
    | `{quest.platforms}` | Where it can be done: Desktop, Mobile, Xbox... |
    | `{quest.starts}` / `{quest.starts_at}` | When it starts, as a relative time / as a date and time |
    | `{quest.expires}` / `{quest.expires_at}` | When it ends, as a relative time / as a date and time |
    | `{quest.limits}` | Region and age limits, or None |
    | `{quest.age_gate}` | 18+ when it has an age limit, otherwise empty |
    | `{quest.status}` | New quest, or Ending soon |
    | `{quest.source}` | discordquest.com |
  </Tab>
  <Tab title="Date & Functions">
    | Variable | Output |
    | --- | --- |
    | `{date}` | Today's date |
    | `{date.now}` | Today's date, Pacific time |
    | `{date.utc_now}` | Current date and time, UTC |
    | `{date.utc_timestamp}` | Current unix timestamp |
    | `{choose:a\|b\|c}` | Random choice from the list |
    | `{range:1-100}` | Random number between 1 and 100 |
    | `{reactreply:emoji}` | Reacts to the message the bot sends with that emoji. Repeat it for more reactions. If the response is only this flag, it reacts to the message that triggered it |
    | `{newline}` | Line break |
    | `{separator}` | Decorative line |
  </Tab>
