## Overview

Info commands are public lookups, nobody needs staff permissions to run them.

## Member & account

<CodeGroup>

```javascript Syntax
/avatar [user]
/banner [user]
/userinfo [user]
/permissions [user] [channel]
```

```javascript Example
/avatar user:@Someone
/permissions channel:#staff-only
```

```javascript Prefix
!avatar @Someone
```

</CodeGroup>

Everything defaults to yourself if `user` is omitted.

## Server

</CodeGroup>

## Small lookups

<CodeGroup>

```javascript Syntax
/snowflake <id>
/color <hex>
/inviteinfo <code>
```

```javascript Example
/snowflake id:1234567890123456789
/color hex:#8399ff
/inviteinfo code:discord.gg/abc123
```

</CodeGroup>

`snowflake` decodes the creation timestamp embedded in any Discord ID (user, channel, role, message).

## Emoji & sticker theft

<CodeGroup>

```javascript Syntax
/steal [emoji]
```

```javascript Example
/steal emoji:🎉
```

</CodeGroup>

Add a custom emoji from another server to this one. Reply to a message containing a sticker instead of providing `emoji` to steal that sticker.

## Getting help

<CodeGroup>

```javascript Syntax
/help [query]
```

```javascript Example
/help
/help query=ticket category add
```

</CodeGroup>

Browse every command, or look one up directly, including a specific subcommand.
