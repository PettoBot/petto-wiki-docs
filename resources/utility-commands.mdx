## Overview

Info commands are public lookups, nobody needs staff permissions to run them.

<Steps>
  <Step title="Look up an account or server">
    Check any member's account with `/userinfo`, or the server's with `/serverinfo`.
  </Step>
  <Step title="Look up a role, channel, or emoji">
    Get details with `/roleinfo`, `/channelinfo`, or `/emojiinfo`.
  </Step>
  <Step title="Petto's own stats">
    Public too, with `/botinfo`, `/ping`, and `/uptime`.
  </Step>
</Steps>

## Commands

| Command | Syntax | Description |
| --- | --- | --- |
| avatar / banner | `/avatar [user]` | A member's avatar or profile banner. |
| userinfo / serverinfo | `/userinfo [user]` | Account, join date, roles, badges, or full server stats. |
| roleinfo / channelinfo / emojiinfo | `/roleinfo <role>` | Details on a role, channel, or custom emoji. |
| permissions | `/permissions <user> [channel]` | A member's effective permissions in a channel. |
| botinfo / ping / uptime | `/botinfo` | Petto's own stats and latency. |
| snowflake / color / firstmessage / inviteinfo | `/snowflake <id>` | Small everyday lookups. |

## Live status

Petto's own uptime and per-shard health are public at [petto.sbs/status](https://petto.sbs/status), reported directly by the bot.
