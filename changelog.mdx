<Update label="2026-10-03">
  **v0.7.0.** Custom commands in code, Quest alerts, Embeds V2 and global stats.

  **[Petto Code](/automation/petto-code)** (in testing)
  - Custom commands can be written in code: a small language of text and `{{ }}` actions with variables, `if`, loops, about 70 functions, embeds, mentions and time. `!customcommand code`, `codeshow`, `codetest` (runs it without sending anything), `template`, `export` and `import`.
  - Buttons and menus that run code, forms that pop up (modals) and reactions that run code. One command holds the whole system.
  - Commands can remember things (counters, points, rankings, cooldowns, lists), per server or per member, and can start on their own prefix or words with `!customcommand trigger`.
  - Embeds can show the avatar next to the author. Ready-made templates: vote, request, claim, suggest, report, profile, role button and role by reaction.
  - A real editor in the dashboard (Automation → Commands in code) that checks the code while you write. Full documentation at [code.petto.sbs](https://code.petto.sbs).

  **[Quest alerts](/automation/quests)**
  - `!quests` posts in a channel when Discord has a new Quest, with the picture, reward, tasks, platforms, dates and limits. Add a role, filter by reward or task, and get a warning before it ends. `!quests list` is for everyone.

  **[Embeds V2](/resources/scripting/embeds#embeds-v2)**
  - A V2 editor in the dashboard: containers, text, pictures, sections, dividers and link buttons. Use the designs in Quest alerts, sanctions, the starboard, verification and bump messages, `!embed send` and `!embed preview`. Shared with the Embed Builder with a `p2.` code.

  **[Global stats](/miscellaneous/global-stats)**
  - A public Stats page (`petto.sbs/stats`) with the messages, voice hours and reactions of all servers, a top 3 of servers and a top 10 of members. A server hides in the dashboard (General), a member with `!globalranking off`.

  **Dashboard and website**
  - The menu has every section in its own group (Moderation, Security, Leveling, Automation, Community...) and is a drawer at the side on a phone.
  - `!help` points to the dashboard, the support server and the Petto Code docs.
  - Fixes: the Cloudflare tunnel no longer writes its token in the logs, and dashboard errors that asked for data that does not exist are fixed.
</Update>

<Update label="2026-10-02">
  **v0.6.1.** The biggest release so far. Every command below is a prefix command.

  **Leveling v2** ([Leveling](/community/leveling))
  - `!rank` answers with a rank card (a picture with the avatar, name, level, position and a progress bar), the improved embed, or both, chosen with `!level rank-style`. The embed shows the position out of all ranked members, the XP missing for the next level, messages or time in voice, the streak and the position this week.
  - Anti-abuse rules with `!level rules`: minimum message length, repeated text, a minimum number of people in voice, and no voice XP while muted. New servers start with 3 characters, repeat protection and 2 people in voice.
  - XP events with `!level event add|remove|list`: a multiplier for hours or days, for all XP, messages or voice, started now or later.
  - Daily bonus and streaks, shown in `!rank`.
  - Weekly and monthly rankings with `!top 1 messages week` and `!top 1 messages month`.
  - Level-up messages can carry an image card, with `!level notify` and `!level voice-notify`.
  - New variables: `{level_next}`, `{level_progress}`, `{level_xp_current}`, `{level_xp_to_next}`, `{level_rank_total}`, `{level_streak}`, `{level_messages}`, `{level_voice_minutes}` and `{level_type}`.
  - The dashboard has a Leveling page to design the rank card, set the rules and XP events, and preview the result.

  **[Image cards](/resources/image-cards)**
  - Pictures drawn for welcome, leave and boost messages, tickets, giveaways, level-up messages, autoresponders and `!embed send`.
  - The basic editor (four layouts, colors, a background image, free fonts) is free. The layer editor and the extra fonts are Premium, and a card keeps working with its basic settings if Premium ends.
  - The advanced card is drawn in the browser while you edit, so layers follow the pointer, and rank cards have a progress bar layer.

  **[Saved embeds everywhere](/guides/saved-embeds-everywhere)**
  - Sanctions (the DM, the reply and the log entry, per type, with `!sanctionmessage`), starboard reposts (`!starboard message`), giveaway messages (`!giveaway message-template`), verification DMs (`!verify template`) and bump messages (`!bumpreminder template`) can use a saved embed. A missing or broken design sends the usual message.
  - New variables: `{case.*}`, `{star.*}`, `{verify.link}` and `{nextBump}`.
  - Everything can also be chosen in the dashboard: Sanction messages under Moderation, the repost design in Automation, a design under each giveaway message, and the verification and bump designs in Onboarding.

  **[Embed code](/resources/scripting/embeds#creating-from-one-code)**
  - `!embed create name code:` builds a whole embed, up to 10, from one code and saves it at once. The Embed code generator on the website builds a message and copies it as a one-line code.

  **Moderation** ([Moderation](/moderation/moderation))
  - [Jail](/moderation/jail): `!jail` and `!unjail`. Timed jails end by themselves, roles come back on release, and jail is an action of warn escalation.
  - `!purge` deletes recent messages by member, kind or text, and `!history` shows everything moderation knows about a member.
  - [Reports](/community/reports): numbered reports with Claim, Resolve, Dismiss, Reopen and Release buttons, categories, cooldown, daily limit, blocking, a reason when closing, a thread that follows the report, Invite reporter, Notify on claim, a settings panel and **Report User** menus.

  **[Fun](/miscellaneous/fun) and utility**
  - `!roll`, `!choose`, `!8ball`, `!ship` with a picture and `!rps`.
  - `!remind 2h text` without `add`, and a `!setup` status panel with a pre-filled quick setup.
  - Info commands and `!case list` redesigned as cards, and roleplay answers that reply to the original message.

  **Customize and Premium**
  - A [name style](/setup/bot-appearance) for Petto in your server, with a gradient, neon or glow, set in the Customize page. It is cleared when Premium ends.
  - The Premium page lists image cards and the new limits, the plans are equal and only differ in the number of servers, and the Free to Premium table is clearer.

  **Dashboard and website**
  - Data loads faster, logging out works in the Spanish and Portuguese dashboards, and menu icons no longer disappear when you change section.
  - Every version of the website's changelog has its own page you can share. The bot's code is public on GitHub under the AGPL-3.0 license and the footer links to it.

  **Fixes**
  - Live counters update again and count the whole member list.
  - Bot commands no longer set off autoresponders, and hints show the prefix that was typed.
</Update>
