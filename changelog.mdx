<Update label="2026-10-02">
  **v0.6.1.** A big release.

  **Leveling v2.** `!rank` answers with a rank card, the improved embed, or both. Anti-abuse rules (`!level rules`), XP events (`!level event`), a daily bonus with streaks, and weekly and monthly rankings (`!top 1 messages week`). See [Leveling](/community/leveling).

  **[Image cards](/resources/image-cards).** Pictures drawn for welcome, leave, boost, tickets, giveaways, level-up messages and more, with a progress bar layer. The basic editor is free, the layer editor and extra fonts are Premium.

  **[Saved embeds everywhere](/guides/saved-embeds-everywhere).** Sanctions (`!sanctionmessage`), the starboard, giveaway messages, verification DMs and bump messages can use a saved embed. New variables: `{case.*}`, `{star.*}`, `{verify.link}` and the leveling variables `{level_next}`, `{level_progress}`, `{level_xp_current}`, `{level_xp_to_next}`, `{level_rank_total}`, `{level_streak}`, `{level_messages}`, `{level_voice_minutes}`, `{level_type}`.

  **[Embed code](/resources/scripting/embeds#creating-from-one-code).** `!embed create name code:` builds a whole embed, up to 10, from one code.

  **Moderation.** [Jail](/moderation/jail), `!purge`, `!history`, and jail as a warn escalation action. [Reports](/community/reports) are numbered, with Claim, Resolve, Dismiss and Reopen buttons, categories, cooldowns, blocking, a reason on closing, threads and **Report User** menus.

  **[Fun](/miscellaneous/fun) and utility.** `!roll`, `!choose`, `!8ball`, `!ship`, `!rps`, `!remind 2h text`, a `!setup` status panel, and info commands and `!case list` redesigned as cards. Premium adds a [name style](/setup/bot-appearance) for the bot per server. Live counters update again.
</Update>

<Update label="2026-09-30">
  **v0.6.0.** The dashboard now speaks Spanish and Brazilian Portuguese (`/es/dash` and `/pt-br/dash`), previews messages like Discord, can send a message to the Embed Builder with a share code and open Embed Builder messages back in the dashboard, and loads faster. Added the full list of embed variables to the dashboard, and [Petto Vanity](/guides/vanity-tag-bot) can now be managed from it, with a public status page. Fixed a crash when an embed command was used without a name.
</Update>

<Update label="2026-09-24">
  **v0.5.1-46.** Added persistent malicious-link detection to [AutoMod](/moderation/automod), per-server independent [case numbers](/concepts/cases), `!case list` without a required user, and [custom command arguments](/automation/custom-commands): `{args}`, `{arg1}` to `{arg10}`, `{args_from:N}`, `{arg_count}`, `{command_name}` and `{prefix}`, with embed-only custom commands. Fixed VoiceMaster interactions, webhook counters, sticky messages and autoresponder database load, and onboarding channel creation on large servers.
</Update>

<Update label="2026-08-31">
  **v0.5.0.** Added Discord linked roles, immediate dashboard prefix synchronization, free server nicknames, clearer setup/removal messaging, and rate limiting for the internal prefix endpoint. `!summary`, `!weekly`, and `!digest` now include the dark Overview-style activity chart with a text fallback. Booster alerts now say `server booster`. Roleplay actions targeting another member now offer one-time Respond/Reject controls, persistent per-server counters, and new commands including `!hi`, `!bye`, `!yes`, `!no`, `!laugh`, `!sad`, and `!angry`.
</Update>
